# Crisp Suite Gate

Modular gateway application built for the Crisp Suite ecosystem. 

## Architecture
- **UI:** `index.html` (Layout, styles, and inline `showSuccess()` UI bindings)
- **Logic:** `repo.js` (Data models, state handlers, and verification logic)
- **Deployment:** Automated via GitHub Actions (`.github/workflows/deploy.yml`) to GitHub Pages.
